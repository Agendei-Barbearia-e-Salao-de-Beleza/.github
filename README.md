O **Agendei.** é uma solução inteligente de agendamento desenhada para unificar a gestão de barbearias (público masculino) e salões de beleza (público feminino) em uma única plataforma intuitiva.

## 🚀 Sobre o Projeto

O objetivo principal é resolver o caos operacional de agendamentos manuais, oferecendo uma interface fluida para o cliente e um painel administrativo eficiente para o profissional. O projeto aplica conceitos rigorosos de engenharia de software para garantir escalabilidade e fácil manutenção.

## 🏗️ Arquitetura e Práticas

Para este projeto, adotamos a **Clean Architecture (Arquitetura Limpa)**, separando as regras de negócio das tecnologias externas. Isso nos permite:
- **Independência de Framework:** O núcleo da aplicação não depende de bibliotecas externas.
- **Testabilidade:** Facilidade em criar testes unitários para a lógica de negócio.
- **Manutenibilidade:** Código organizado em camadas claras (Domain, Use Cases, Adapters, Infrastructure).

## 🛠️ Stack Tecnológica

- **Backend:** Java 17+ com Spring Boot 3.x
- **Frontend:** Kotlin (Mobile/Web)
- **Banco de Dados:** PostgreSQL (Relacional) ou MongoDB/Firebase (NoSQL) - *Definindo estratégia de persistência*
- **Segurança:** Spring Security & JWT
- **Documentação:** Swagger (OpenAPI)
