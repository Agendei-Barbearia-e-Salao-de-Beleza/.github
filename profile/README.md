O **Agendei.** é uma solução inteligente de agendamento inspirada no **Booksy**, desenhada para unificar a gestão de barbearias e salões de beleza em uma única plataforma intuitiva, elegante e de alta performance.

## 🚀 Sobre o Projeto

O objetivo principal é resolver o caos operacional de agendamentos manuais, oferecendo uma interface fluida para o cliente e um painel administrativo completo (Dashboard) para o profissional. O projeto aplica conceitos rigorosos de engenharia de software para garantir que o produto final seja digno de um portfólio profissional de alto nível.

## 🏗️ Arquitetura e Práticas

Para este projeto, adotamos a **Clean Architecture (Arquitetura Limpa)** e o **Spec Driven Development (SDD)**, o que nos garante:
- **Independência de Framework:** O núcleo da aplicação é isolado e focado nas regras de negócio.
- **Alta Testabilidade:** Facilidade em validar processos críticos como conflitos de horário.
- **Documentação Viva:** Uso de especificações técnicas rigorosas antes de cada etapa de codificação.

## 🛠️ Stack Tecnológica

- **Backend:** Java 21+ com Spring Boot 3.x
- **Mobile App:** Kotlin com Jetpack Compose (Material Design 3)
- **Web Dashboard:** TypeScript com Next.js 14 e Tailwind CSS
- **Banco de Dados:** PostgreSQL (Supabase) & MongoDB (Atlas)
- **Infraestrutura:** Docker & Firebase (FCM para Notificações)
- **Comunicação:** Integração direta com API do WhatsApp
